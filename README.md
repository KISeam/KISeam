## 🚀 About Me

* Full-stack software engineer based in **Dhaka, Bangladesh 🇧🇩** with **2+ years of professional industry experience**.
* I build fast, scalable web applications and the backend services behind them — from the interface down to the **Linux VPS** they run on.
* Main stack: **TypeScript, Next.js, React, NestJS, Prisma, PostgreSQL**, plus **Node.js/Express, Laravel, MongoDB and MySQL** where the project calls for them.
* I like problems that need more than a screen: **data models, permissions, payments, real-time updates**, and the interfaces that make them usable.
* I spend extra time on the edges where products break — the retried payment, the cache that goes down, the file with the wrong extension, the visitor using a keyboard.
* 📚 **Currently studying:** C# & .NET Clean Architecture · System Design · Data Structures & Algorithms
* 🌐 Portfolio & case studies: [khairulislamseam.com](https://khairulislamseam.com)

### 🧠 How I Work

1. **Understand before building** — people, data and constraints first, code after.
2. **Engineering over shortcuts** — validation at the boundary, types end to end, designed failure paths.
3. **Problem-solving mindset** — decompose, pick the data structure, measure, then optimise.
4. **Performance & reliability** — systems degrade gracefully instead of falling over.
5. **Continuous improvement** — every project leaves something new to learn.
6. **User-centered development** — fast, readable interfaces that work with a keyboard, a screen reader and a slow phone.
